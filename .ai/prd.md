## Problem & Context

axis-iliad is a monorepo built with TypeScript using React. It contains 500 files across 9 top-level directories. It defines 278 domain models.

## Goals

- Deliver 174 HTTP endpoints (4 methods) backing the user-facing surface.
- Maintain a stable, typed contract over 278 domain models with no breaking changes within a minor version.
- Ship a responsive UI that meets WCAG 2.1 AA accessibility on the primary user flows.
- Land all changes behind tests; keep the green-build invariant for the main branch.

## Non-Goals

- Backwards compatibility with deprecated APIs or pre-snapshot data formats.
- Server-side rendering (this version is a client-rendered app).
- Premature optimization — first build it, measure, then optimize.
