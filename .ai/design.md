## UI / UX Decisions

- **Component model**: React function components. No class components.
- **Accessibility**: WCAG 2.1 AA on primary flows. Every interactive element ships keyboard-navigable.
- **State**: prefer co-located state and URL-driven routing; introduce a store only when state spans 3+ unrelated components.
- **Loading & error states**: every async surface ships explicit loading + error UI, no silent fallbacks.
