# iliad-md

> **Naming:** the npm package is `iliad-md`; the installed bin command is `iliad`. With `npx`, always use the package name: `npx iliad-md`. The bare `iliad` name on npm is squatted by an abandoned v0.0.0 package (2022) and could be pursued later via npm's package-name dispute process.

Generate and maintain agent-context files for a repository from static analysis. One scan produces five files, all derived from what is actually in the repo (languages, frameworks, package manager, test setup, directory layout, domain models):

| Target | File | Purpose |
|--------|------|---------|
| `agents` | `AGENTS.md` | Canonical agent instructions |
| `claude` | `CLAUDE.md` | Same content, Claude Code heading |
| `cursor` | `.cursorrules` | Condensed imperative rules for Cursor |
| `copilot` | `.github/copilot-instructions.md` | Condensed rules for GitHub Copilot |
| `gemini` | `GEMINI.md` | Same canonical content, Gemini heading |

Zero runtime dependencies. Output is byte-deterministic: the same repo state always produces the same bytes, so the files diff cleanly and `check` mode works in CI.

## Quickstart

```bash
npx iliad-md                 # scan the current directory, write all five files at the repo root
npx iliad-md --targets agents,claude
npx iliad-md --dir path/to/repo
npx iliad-md --dry-run       # show what would be written, write nothing
```

(With the package installed, the command is simply `iliad`.)

## Check mode (CI)

`check` regenerates everything in memory, diffs against the files on disk, prints a per-file summary, and exits 1 on any drift:

```bash
npx iliad-md check
```

```yaml
# .github/workflows/iliad.yml
- run: npx iliad-md check
```

## GitHub mode

Fetch a public repository (tarball API, no auth) and generate into an output directory instead of the repo root:

```bash
npx iliad-md github https://github.com/owner/repo --out ./iliad-output
```

## Marker protection

Every generated file starts with a marker line (`generated by iliad`). The CLI **never overwrites a file that lacks the marker** — a hand-written `AGENTS.md` is skipped with a warning unless you pass `--force`.

## Flags

| Flag | Meaning |
|------|---------|
| `--dir <path>` | Repo to scan (default: cwd) |
| `--out <dir>` | Output directory for `github` mode (default: `./iliad-output`) |
| `--targets <list>` | Comma-separated subset of `agents,claude,cursor,copilot,gemini` (default: all) |
| `--dry-run` | Print what would be written without writing |
| `--force` | Overwrite files that lack the generated-by marker |
| `--quiet` | Suppress non-error output |
| `--version` | Print version |
| `--help` | Usage |
