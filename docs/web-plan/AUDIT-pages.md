## Navigation model
- **No router dependency** — `package.json` deps are only `react`, `react-dom`, `jszip`. Pages are a string-union state machine: `type Page` union (`App.tsx:57-76`), `useState<Page>`, hash-based sync via a `hashchange` listener with a hand-written if/else chain (`App.tsx:189-240`), plus a pathname alias table for marketing URLs (`/pricing`, `/mcp`, `/docs`, `/tools/web-research`… `App.tsx:111-125`). Sub-tools use `#tools/web-research` style (`pageFromHash` :128-135, `hashForPage` :244-248).
- **Adding a page touches ~7 sites**: Page union, `SECTION_OF`/`LABEL_OF` (:92-105), `pageFromHash`/`pageFromPathname`, `getInitialPage`, the render block (:502-529), sidebar tree (:451-471), mobile drawer (:544-563), optionally palette/shortcuts.
- **Shell**: 3-column IDE layout ("cockpit") — icon rail + collapsible file-tree sidebar (WORKSPACE/LIBRARY/ACCOUNT/HELP groups) + tabstrip breadcrumb + single scrolling `.ide-main` (`index.css:867-1032`); landing gets a "hybrid" wider marketing treatment (`.is-landing`, `index.css:1028-1032`). CommandPalette on Ctrl+K (`components/CommandPalette.tsx`), Ctrl+1–9 page shortcuts (`App.tsx:403-422`), Alt+1–6 dashboard-tab shortcuts (`DashboardPage.tsx:62-74`). Fixed 32px StatusBar (z-index 8000).

## Auth model
- **HttpOnly cookie session** (H1): `axis_session` cookie carries auth; `localStorage.axis_api_key` holds only the marker `"__cookie_session__"` (`api.ts:317`). Flows: `establishSession(rawKey)` (`api.ts:334`), `markAuthed()` (:328), `migrateLegacyKey()` one-time migration run on App mount (`App.tsx:303-305`), `logoutSession()` (:373). All fetches `credentials:"include"` + legacy bearer fallback (`authHeaders` :319-324). OAuth: GitHub/Google full-page nav → `/account?code=` → `exchangeOAuthCode` (`AccountPage.tsx:49-68`); `isOAuthCallback()` guard keeps the login gate from eating the callback (`App.tsx:86-88, 335-342`).
- **Gating**: `AUTH_ONLY_PAGES` = admin/myanalytics/account/plans/paid-checkout (`App.tsx:81`); logged-out hit opens SignUpModal and bounces (:335-342). **Admin detection is a probe**: success of `getAdminStats()` sets `privateAccess` (`App.tsx:310-329`); non-admins on admin/myanalytics bounce to account (:347-352). "Logged in" checks everywhere are `!!localStorage.getItem("axis_api_key")`.

## Hard constraints & gotchas for any redesign
1. **No router** — hash+state navigation; introducing react-router violates "no new deps without discussion" (CLAUDE.md).
2. **No charting lib** — any "usage graphs" must be hand-rolled SVG/CSS or a discussed dep.
3. **No class components** except the mandated `ErrorCatcher` (`App.tsx:27-39`).
4. **Single-snapshot persistence** — whole app assumes one `SnapshotResponse` in localStorage; a Projects/History page needs new API client functions (none exist in `api.ts`) and state rework.
5. **PAI'D is the only checkout path** (comments `PlansPage.tsx:43-45`, `AccountPage.tsx:139`); never wire Stripe directly.
6. **Cookie auth invariants** — never persist raw keys; use `establishSession`/`markAuthed` (`api.ts:313-356`).
7. **Two divergent API bases**: `api.ts:4` (`api.iliad.trustfabric.ai`) vs `ForAgentsPage.tsx:2` / `InstallPage.tsx:4` (`axis-api-6c7z.onrender.com`) — plus hardcoded tool/program/count copy (141/20/35) duplicated across ≥6 files (UploadPage, ProgramsPage, DocsPage, InstallPage, ForAgentsPage, ProgramLauncher) with known drift risk (memory: counts must be diffed against `counts.ts`).
8. Tests exist and will constrain refactors: `pages.test.tsx`, `api.test.ts`, `upload-utils*.test.ts`.
9. `MyAnalyticsPage` (the closest thing to user usage graphs) is currently admin-only by gate, not by API contract (`App.tsx:81, 347-352`).
